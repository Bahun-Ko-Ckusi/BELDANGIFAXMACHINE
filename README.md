# Beldangi Fax Machine LC

Company site for Beldangi Fax Machine LC, a one-person software studio in Vermont:
games, mobile apps, and websites for small businesses.

Live: https://bahun-ko-ckusi.github.io/BELDANGIFAXMACHINE/

## Files

| File | What it is |
| --- | --- |
| `index.html` | The whole site — one page, four "pages" of a fax transmission |
| `styles.css` | All styling. Palette and type live in the `:root` block at the top |
| `404.html` | Not-found page |
| `favicon.svg` | Tab icon |

Static HTML and CSS, no build step. Edit the files, commit, push — GitHub Pages
serves `main` at the repo root.

## Design notes

The site is laid out as a fax transmission because of the company name: the hero is
a real cover sheet (From / To / Re / Pages), each section is a numbered page with a
margin stamp, and the services section prints in negative. Palette is thermal paper,
black toner, dialtone blue, and a magenta that landed slightly out of register.
Type is Archivo with IBM Plex Mono for the transmission metadata.
